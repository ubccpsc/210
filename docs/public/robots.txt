# Crawling policy for the CPSC 210 textbook.
#
# The textbook is published under CC BY-NC-SA 4.0. Training a commercial model
# on it is not a use the licence grants, so the crawlers below are asked not to
# take it. Conventional search engines are welcome: finding this book in a
# search result is the point of publishing it on the open web.
#
# IMPORTANT: robots.txt is only honoured at the root of a host. This file is
# served at https://ubccpsc.github.io/210/robots.txt, which crawlers do NOT
# read. For these rules to take effect they must live at
# https://ubccpsc.github.io/robots.txt, which is served from the org's
# ubccpsc.github.io repository, or the book must move to a domain of its own.
# Until one of those happens, the opt-out that does apply here is the
# <meta name="robots" content="all, noai, noimageai"> tag set in
# docs/.vitepress/config.mts, which travels with each page.
#
# This is a request, not a control. Well-behaved crawlers honour it; nothing
# obliges the rest to.
