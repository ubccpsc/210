# Reference

This section collects reference materials that are meant to be returned to rather than read in order.

- [Why CPSC 210 Exists](../why-this-course) makes the case for a software construction course centred on code fluency, even when generative AI models can write code.
- [GenAI and You](../gen-ai-and-you) explains the course's generative AI policy (not allowed on in-class exercises or exams, allowed but discouraged on labs, allowed on the project) and the research behind it.
- [Prerequisite Knowledge](./prerequisite-knowledge) reviews the CPSC 110 and CPSC 121 ideas the textbook builds on, and where each one reappears.
- [Uncovered Language Features](./language-features) describes the parts of TypeScript this course deliberately leaves out, and the reasoning behind each, so you can recognize them in code you did not write.
- [Glossary](./glossary) collects the terms defined in bold throughout the textbook, each linked back to the section that introduces it.

## Cookbooks

The [cookbooks](./cookbooks/) provide practical guides to some domain-specific knowledge the course relies on.

- [Version Control Cookbook](./cookbooks/git/git) describes git, and lists the commands for getting a repository, sharing changes, and working with branches.
- [IDE Cookbook](./cookbooks/vscode/VSCode) covers Integrated Development Environments, focusing on VSCode and looks at finding your way around the editor, reading compile, lint, and test results, and installing VSCode on your own computer.
- [Web Service Cookbook](./cookbooks/rest/REST) explains how a REST-based web service receives and responds to requests.
- [Document Object Model Cookbook](./cookbooks/dom/DOM) explains how a TypeScript program reads and changes a web page's DOM.
- [Grading Cookbook](./cookbooks/grader/Grader) explains the report you see after pressing Save & Grade: the bucket grades, the six checks, and how to use the feedback.
