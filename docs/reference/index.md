# Reference

This section collects reference materials that are meant to be returned to rather than read in order.

- [Why CPSC 210 Exists](../why-this-course) makes the case for a software construction course centred on code fluency, even when generative AI models can write code.
- [GenAI and You](../gen-ai-and-you) explains the course's generative AI policy (not allowed on in-class exercises or exams, allowed but discouraged on labs, allowed on the project) and the research behind it.
- [Prerequisite Knowledge](./prerequisite-knowledge) reviews the CPSC 110 and CPSC 121 ideas the textbook builds on, and where each one reappears.
- [Uncovered Language Features](./language-features) describes the parts of TypeScript this course deliberately leaves out, and the reasoning behind each, so you can recognise them in code you did not write.
- [Glossary](./glossary) collects the terms defined in bold throughout the textbook, each linked back to the section that introduces it.
