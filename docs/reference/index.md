# Reference

This section collects reference materials that are meant to be returned to rather than read in order.

- [Uncovered Language Features](./language-features) describes the parts of TypeScript this course deliberately leaves out, and the reasoning behind each, so you can recognise them in code you did not write.
- [Glossary](./glossary) collects the terms defined in bold throughout the textbook, each linked back to the section that introduces it.
- [Why This Course](../why-this-course) makes the case for having a code-fluency-centric software construction course, even when generative AI models can write code.
- [GenAI and You](../gen-ai-and-you) describes the rationale behind our split Generative AI policy (prohibited on exams, allowed/discouraged on labs/project), including results from the educational literature on how GenAI use can hamper learning outcomes.
