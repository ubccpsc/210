# Cookbooks

The cookbooks are practical guides to the tools the course uses.

- [Version Control Cookbook](./git/git) lists the git commands for getting a repository, sharing changes, and working with branches.
- [Development Environment Cookbook](./vscode/VSCode) covers finding your way around the VSCode, compiling, running, and debugging your code.
- [REST Cookbook](./rest/REST) explains how a web service receives requests and answers them.
- [DOM Cookbook](./dom/DOM) explains how a TypeScript program reads and changes a web page.
- [Grading Cookbook](./grader/Grader) explains the course auto grader and what its reports mean.
