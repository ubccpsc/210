# Cookbooks

The cookbooks are practical guides to the tools the course uses. Each one is organized around tasks, so you can go straight to the section you need.

- [Git Cookbook](./git/git) lists the commands for getting a repository, sharing changes, and working with branches.
- [VSCode Cookbook](./vscode/VSCode) covers finding your way around the editor, reading compile, lint, and test results, and installing VSCode on your own computer.
- [REST Cookbook](./rest/REST) explains how a web service receives requests and answers them: requests and responses, status codes, trying a service with `curl`, and testing one.
- [DOM Cookbook](./dom/DOM) explains how a TypeScript program reads and changes a web page, for the labs and project phases that build one.
- [Grading Cookbook](./grader/Grader) explains the report you see after pressing Save & Grade: the bucket grades, the six checks, and how to use the feedback.
